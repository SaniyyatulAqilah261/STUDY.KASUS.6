Program tersebut digunakan untuk mengelola data toko menggunakan file JSON. import json berfungsi untuk menggunakan fitur JSON, sedangkan open() digunakan untuk membuka atau membuat file data toko.json. json.load() digunakan untuk mengambil data dari file JSON dan menyimpannya ke variabel data. Fungsi tambah_data() digunakan untuk menambahkan data barang baru berupa nama, kode, dan kategori ke dalam data. Fungsi simpan_file() digunakan untuk menyimpan data yang sudah ditambahkan kembali ke file JSON menggunakan json.dump(). Kemudian, while True digunakan agar menu program terus berjalan sampai pengguna memilih keluar. Pilihan 1 digunakan untuk melihat data, pilihan 2 untuk menambahkan data baru, pilihan 3 untuk menyimpan data ke file, dan pilihan 4 untuk keluar dari program menggunakan break. if, elif, dan else digunakan untuk menentukan tindakan berdasarkan pilihan pengguna, sedangkan for digunakan untuk menampilkan setiap data barang yang ada.
